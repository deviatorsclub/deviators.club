# Deviators Club Website

![Deviators Club](/public/og-image.png)

Welcome to the official repository for the **Deviators Club** website! 🚀

Deviators Club is a dynamic, student-led tech community focused on empowering coders, builders, and dreamers to learn, build, and lead. We run workshops, hackathons, and collaborate on cutting-edge open-source projects.

Visit us at [deviators.club](https://www.deviators.club).

## Tech Stack

This website is built using modern web technologies to ensure optimal performance, SEO, and developer experience:

- **Framework**: [Next.js](https://nextjs.org/) (React 19)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://motion.dev/)
- **Icons**: [Hugeicons](https://hugeicons.com/)
- **Deployment**: [Vercel](https://vercel.com/)

## Getting Started

To run this project locally, simply clone the repository and run the development server. We use `pnpm` as our package manager.

```bash
# Install dependencies
pnpm install

# Run the development server
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
